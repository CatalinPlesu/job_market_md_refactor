# Job Market Scraper & Analyzer

This project scrapes job listings from multiple sources, processes the data, and provides analysis and visualization tools.

## Features

- **Automated scraping** from Rabota.md and LinkedIn.
- **Data processing** and deduplication.
- **Systemd integration** for scheduled, background scraping.
- **Analysis notebook** for data exploration and visualization (uses `matplotlib` heavily).

---

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/CatalinPlesu/job_market_md_refactor
cd job_market_md_refactor
```

### 2. Create and activate a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install required packages

Install only the packages used by this project (identified by hand):

```bash
pip install tinydb python-dotenv pandas openai selenium beautifulsoup4 requests matplotlib
```

- `tinydb` – for lightweight database storage
- `python-dotenv` – for loading environment variables
- `pandas` – for data processing
- `openai` – for AI-powered data extraction
- `selenium` – for web scraping (LinkedIn)
- `beautifulsoup4` – for HTML parsing (Rabota.md)
- `requests` – for HTTP requests
- `matplotlib` – for data visualization in the analysis notebook

## Environment Variables

Create a `.env` file in the project root with the necessary secrets (API keys, etc).  
This file will be loaded automatically by the code.

Example:

```
API_KEY=your_openai_key
LINKEDIN_EMAIL=your_email@example.com
LINKEDIN_PASSWORD=your_linkedin_password
# Add other variables as needed
```

> **Note:** LinkedIn scraping requires a valid LinkedIn account. Your credentials are needed for automated access.

## Systemd Integration

The project includes systemd unit files for running the scraper automatically in the background.

### 1. Update paths

Edit the files in `systemd/` to ensure all paths match your environment.

### 2. Install the service and timer

From the `systemd/` directory, run:

```bash
sudo make install
```

This will:

- Copy the service and timer files to `/etc/systemd/system/`
- Enable and start the timer (runs the scraper 3x/day)

### 3. Uninstall

```bash
sudo make uninstall
```

Activate your venv and run:

```bash

```

## Configuration Options

The following options are defined in `config.py` and control the behavior of the scraper and processor:

- **DB_FILE**: Name of the TinyDB database file (default: `data.json`).
- **TABLE_ROBOTA_MD_RAW**: Table name for raw Rabota.md data (default: `robota_md_raw_data`).
- **TABLE_LINKEDIN_RAW**: Table name for raw LinkedIn data (default: `linkedin_raw_data`).
- **TABLE_PROCESSED**: Table name for processed job data (default: `processed_data`).
- **URL_ROBOTA_MD**: URL for scraping Rabota.md IT jobs (default: `https://www.rabota.md/ro/vacancies/category/it/developers/`).
- **URL_LINKEDIN**: URL for scraping LinkedIn jobs (default: a Moldova-focused search, see config.py for the latest value).
- **API_URL**: The endpoint for the OpenAI-compatible API (default: `https://openrouter.ai/api/v1`).
- **MODEL**: The model used for job data extraction (default: `deepseek/deepseek-chat:free`).
- **CONTEXT**: System prompt for the AI extraction assistant (see `config.py` for the full text).
- **JOB_SCHEMA_PROMPTv2**: Detailed instructions and schema for extracting job data as JSON (see `config.py` for the full schema and rules).

> **Note:** The schema in `config.py` defines all the fields that will be extracted from job posts, including normalization rules and expected data types. You can customize these options to adapt the project to your needs.
